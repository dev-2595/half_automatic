# 지식 (Knowledge) — 기획 01: 영역과 학습 진행 구조

> 상태: 초안 (v0.4) · 출처: 기획자 설정
> §1은 확정, §2는 근거 조사 결과, §3은 결정이 필요한 사항이다.

## 1. 확정 사항

### 1.1 게임 구조 (v0.3에서 확정)

```
처음 화면 ─ 8개 영역(과목)
            └─ 영역 선택 (예: 수학의 신의 세계)
                └─ 기초 / 응용 / 심화  (세 갈래 맵)
                    └─ 각 갈래 안이 초등 / 중등 / 고등으로 나뉜다
                        └─ 기초 맵 = 일반 진도(예: 수학은 더하기부터)가 표시된 맵
                            · 플레이어가 학습할 학년과 레벨을 선택할 수 있다
                            · 진도는 고등학교 3학년 개념까지 올라간다
```

영역 하나는 3갈래(기초·응용·심화) × 3학교급(초등·중등·고등) = **9개 구역**이고, 8개 영역 전체로는 **72개 구역**이다. 콘텐츠 제작 규모를 가늠하는 기준으로 쓴다.

| # | 내용 |
|---|---|
| D1 | 영역은 8개이며, 플레이어가 **직접 선택**한다. |
| D2 | **처음부터 8개 영역이 모두 열려 있다.** (진행 순서 제약 없음) |
| D3 | 여러 영역을 오갈 수 있어 여러 교과를 병행해서 학습할 수 있다. |
| D4 | 영역 안에서는 **스토리를 진행하며** 학습도 **점점 더** 진행한다. |
| D5 | 학습 난이도는 쉬운 것에서 시작해 **고등학교 3학년 개념까지** 점점 어려워진다. |
| D6 | 영역에 들어가면 **기초 · 응용 · 심화** 세 갈래 맵이 있다. |
| D7 | **기초 맵**에는 **일반 진도**가 표시된 맵이 있고, 가장 쉬운 개념부터 시작한다. (수학이면 **더하기**부터) |
| D8 | 플레이어는 **학습할 학년과 레벨을 선택**할 수 있다. |
| D9 | **기초 · 응용 · 심화 각각의 안이 초등 · 중등 · 고등으로 나뉜다.** (예: 응용 안에 초등·중등·고등) |

### 1.2 변경 이력

| 이전 설정 | 지금 |
|---|---|
| "초등학교 1학년 수준에서 시작" (D5) | 시작점은 **가장 쉬운 개념**이고, 학년·레벨을 **선택할 수 있다** (D7, D8) |
| "모든 영역이 1단계에서 시작, 학년과 1:1 대응 안 함" (D6) | 학년이 **선택 항목으로 등장**하므로 실제 학년과 연결된다. 교과별 시작 학년 차이(§2)가 다시 중요해진다 |
| "난이도의 끝: 초6 / 중3 / 고3 중 미정" | **고3 개념까지** (수학 기준으로 확정, 다른 영역도 같은지는 §3 Q3). 초·중·고 구분은 D9 |

## 3. 결정이 필요한 사항

### Q1. 세 갈래 · 세 학교급 · 별 3개의 관계 (가장 중요)
이제 **3개씩인 구분이 세 가지**다: 갈래(기초·응용·심화), 학교급(초등·중등·고등), 그리고 기획 02의 **별 3개(초급·중급·상급)**. 이름도 비슷하다(초급·중급·상급 ↔ 초등·중등·고등).
별이 무엇에 대응하는지 알려 주세요.

| 읽는 법 | 설명 |
|---|---|
| **A. 갈래 = 별** | 한 개념을 기초 갈래에서 클리어하면 ★, 응용에서 ★★, 심화에서 ★★★ |
| **B. 학교급 = 별** | 초등 구역을 클리어하면 ★, 중등이면 ★★, 고등이면 ★★★ (초급·중급·상급 = 초등·중등·고등) |
| **C. 개념 안 4단계** (기획 02 §1 예시) | 곱셈 하나가 구구단(기본) → 십의 단위(보통) → 응용 → 심화의 4개 스테이지. 갈래·학교급 구분과는 별개 |
| D. 그 밖의 구조 | 직접 설명해 주세요 |

자세한 비교는 [기획 02 §2](02_skill_system.md).

### Q2. 학년·레벨 선택 (D8)
- **"레벨"** 은 무엇인가? (예: 학년 안의 난이도 상/중/하, 또는 단원 순서, 또는 플레이어 레벨)
- 선택은 **학교급(초·중·고) → 학년** 순서인가, 학년 하나만 고르는가?
- 학년을 고르면 **그 아래 진도는 어떻게 되는가?**
  - 건너뛰기: 자동 완료 처리 / 그냥 잠금 해제만 / 다시 풀 수 있게 열어 둠
- 선택한 학년·레벨은 **중간에 바꿀 수 있는가?**
- 높은 학년을 고르면 보상·경험치에 영향이 있는가?

### Q3. 기초 외 맵과 영역별 차이
- 응용·심화 갈래도 초·중·고로 나뉘는 것은 확정(D9). 다만 **갈래 안의 맵 구성**(기초처럼 학년별 진도 맵인가)과 **열리는 조건**(기초를 마쳐야 하나, 처음부터 열려 있나)은 미정
- 수학 외 다른 영역도 **고3 개념까지** 올라가는가? 영어·정보처럼 초등 시작 학년이 다른 교과(§2)는 학년 선택을 어떻게 보여주나?
- 교과명 비공개 규칙의 범위: 신·영역 이름은 개념 이름으로 숨기지만, **영역 안의 맵에는 학년·진도(교과 내용)가 드러난다.** 이 구분이 의도한 것인가?
