## 2. 근거 조사: 실제 교육과정과 "초1 시작"

D5를 모든 영역에 똑같이 적용하면 실제 교육과정과 어긋나는 교과가 있다.
교육부 고시 원문은 이 환경에서 확인하지 못했고, 아래는 보도·자료 기준이다.

| 교과 (영역) | 초등에서 시작하는 학년 | 확인 상태 | 출처 |
|---|---|---|---|
| 국어 (생명) | 1학년 | 확인 | [아시아경제](https://view.asiae.co.kr/article/2022122211013751722) |
| 수학 (공간) | 1학년 | 확인 | 위와 같음 |
| 영어 (화합) | **3학년** | 확인 | [웅진씽크빅 보도](https://sateconomy.co.kr/news/view/1065577888868865) |
| 정보 (꿈) | **5~6학년** 실과 안의 정보 단원 | 확인 (의무/권장 여부는 원문 확인 필요) | [뉴시스](https://www.newsis.com/view/NISX20220819_0001984577) |
| 사회 (정의), 과학 (이성) | 3학년으로 알려져 있음 | **미확인** | — |
| 역사 (시간) | 사회 교과 안에서 다루는 것으로 알려져 있음 | **미확인** | — |
| 음악 (감정) | 1~2학년은 통합교과 안에 포함되는 것으로 알려져 있음 | **미확인** | — |

- 1~2학년 교과의 중심은 국어, 수학, 통합교과다.
- 개정 교육과정은 2024년 초1·2부터 순차 적용되어 2026년 현재 초1~6이 대상이다.
- 정확한 편제는 교육부 고시 「2022 개정 교육과정」 총론·각론 원문으로 확정해야 한다.

## 3. 결정이 필요한 사항

### Q1. 영어·정보 영역도 "초1 수준"에서 시작하나? — **해결됨**
- 확정: **모든 영역이 가장 쉬운 것부터 시작한다 (안 A).** 영어 1단계는 알파벳·기초 단어,
  정보 1단계는 순서·규칙 찾기처럼 누구나 시작할 수 있는 내용으로 만든다.
- 교과별 실제 시작 학년(§2)은 **콘텐츠를 만들 때의 참고 자료**로만 쓴다.
- 영역별 시작 지점은 데이터로 지정할 수 있게 해 두어, 나중에 바꿀 여지를 남긴다.

### Q2. 난이도의 끝은 어디인가?
- [ ] 초6까지 / 중3까지 / 고3(수능 수준)까지 중 어디인가
- ※ "쭉 거슬러 올라가면서"를 **학년이 올라가는 방향**(초1 → 위 학년)으로 이해했다. 맞는지 확인 필요.

### Q3. 진행도를 영역마다 따로 관리하나?
