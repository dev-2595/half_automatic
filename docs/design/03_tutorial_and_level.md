# 지식 (Knowledge) — 기획 03: 튜토리얼과 레벨

> 상태: 초안 (v0.1) · 출처: 기획자 설정
> §1은 확정, §2는 확정 내용에서 도출한 규칙(제안), §3은 결정이 필요한 사항이다.
> 용어: **영역** = 과목 하나의 세계(기획자가 "지역·구역"이라 부르는 것). **구획** = 영역 안의 갈래 × 학교급 단위 (기획 01 §1.1).

## 1. 확정 사항

### 1.1 레벨

| # | 내용 |
|---|---|
| L1 | 레벨은 **1부터 100까지**다. |
| L2 | 레벨은 **영역(과목)마다 따로** 관리한다. 한 과목의 레벨과 점수는 다른 과목에 영향을 주지 않는다. |
| L3 | **100레벨 = 그 영역의 모든 개념과 심화를 익힌 수준**이다. (예: 수학에서 고등학교 3학년 심화까지 마치면 100레벨) |
| L4 | 100레벨은 **과목마다 각각** 달성해야 한다. 수학 100레벨이 국어·영어·과학 등의 레벨에 영향을 주지 않는다. |

### 1.2 튜토리얼

| # | 내용 |
|---|---|
| T1 | 튜토리얼은 **영역마다 하나씩**, 총 **8개**다. |
| T2 | **가장 먼저 하는 튜토리얼(처음 들어간 과목)** 에서만 **조작법을 알려 준다.** 조작법 안내 → 테스트 문제 → **보스 소환** 순서다. |
| T3 | 그 뒤에 하는 **다른 영역의 튜토리얼은 조작법 없이 실력 테스트만** 한다. |
| T4 | 실력 테스트 결과로 플레이어를 **맞는 수준(초등 / 중등 / 고등)** 으로 보낸다. |
| T5 | 테스트 문제는 **과목마다 따로** 있다. |

## 2. 규칙으로 정리 (제안)

### 2.1 플레이어 진행 데이터

| 범위 | 항목 | 설명 |
|---|---|---|
| 전체 (1개) | `ControlsTutorialDone` | 조작법 안내를 마쳤는가 |
| 영역별 (8개) | `TutorialDone` | 이 영역의 튜토리얼을 마쳤는가 |
| 영역별 | `PlacementSchoolLevel` | 실력 테스트로 정해진 학교급 (없음 / 초등 / 중등 / 고등) |
| 영역별 | `Level` | 1~100 |
| 영역별 | `Exp` | 현재 레벨의 누적 경험치 |

### 2.2 지켜야 할 불변 조건 (저장 데이터를 불러올 때 거부)

1. `Level`은 1 이상 100 이하이고 `Exp`는 0 이상이다.
2. `PlacementSchoolLevel`이 정해져 있으면 그 영역의 `TutorialDone`은 참이다. (반대로 `TutorialDone`이 거짓이면 학교급은 없음)
3. 어떤 영역이든 `TutorialDone`이 참이면 `ControlsTutorialDone`도 참이다. 조작법은 **처음 한 번만** 나온다.
4. 영역끼리 `Level`과 `Exp`를 **공유하지 않는다.** (L2)

### 2.3 튜토리얼 흐름

```
[처음 들어간 영역]  조작법 안내 → 테스트 문제 → 보스 소환 → 결과로 학교급 배정   (ControlsTutorialDone = 참)
[이후 다른 영역]    (조작법 없음) 테스트 문제 → 결과로 학교급 배정
```

- 조작법 안내 도중 종료하면 `ControlsTutorialDone`은 **거짓**으로 남기고 다음 접속에서 다시 보여 준다. (제안)

### 2.4 레벨과 경험치 데이터의 정합성

L3 때문에 **영역 하나의 모든 스테이지 보상을 합친 경험치**가 **100레벨에 필요한 누적 경험치**와 맞아야 한다.
(너무 적으면 모든 개념을 마쳐도 100레벨에 못 가고, 너무 많으면 심화를 다 마치기 전에 100레벨이 된다.)
데이터로 관리할 때 로드 시점에 검사한다. (제안)

1. 영역별 **스테이지 보상 총합 ≥ 100레벨 누적 필요 경험치**
2. 마지막 스테이지(고등 심화)를 빼면 **총합 < 100레벨 누적 필요 경험치**
   → 100레벨은 모든 개념과 심화를 마쳐야만 도달한다는 L3를 보장한다.

## 3. 결정이 필요한 사항

### Q1. 레벨 1~100과 구획 9개의 대응
영역 하나는 3갈래(기초·응용·심화) × 3학교급(초등·중등·고등) = 9구획이다. 레벨이 오르는 순서가 어느 쪽인가?

| 안 | 순서 |
|---|---|
| A. 갈래 먼저 | 기초(초→중→고) → 응용(초→중→고) → 심화(초→중→고) |
| B. 학교급 먼저 | 초등(기초→응용→심화) → 중등(…) → 고등(기초→응용→심화) |
| C. 기타 | 직접 설명해 주세요 |

"수학에서 고3 심화까지 마치면 100레벨"이므로 **마지막 구획은 고등 심화**다. (A, B 모두 만족)

### Q2. 실력 테스트 결과는 무엇을 정하는가?
- **학교급만** 정하는가, **시작 레벨까지** 정하는가? (예: 중등 판정이면 레벨 35에서 시작)
- 앞서 정한 **학년·레벨 직접 선택**([기획 01 D8](01_learning_structure.md))과의 관계: 테스트가 **대신하는가**, 테스트 후 **직접 조정**할 수 있는가?
- 테스트를 **다시 볼 수 있는가?**

### Q3. 튜토리얼의 보스
- 보스는 **모든 영역의 튜토리얼**에 나오는가, 첫 튜토리얼에만 나오는가?
- 보스는 테스트 문제와 어떻게 연결되는가? (예: 문제를 맞히면 보스에게 피해)
- 결과가 낮아도 보스를 이길 수 있는가, 실패하면 어떻게 되는가?

### Q4. 튜토리얼을 건너뛸 수 있는가?
- 튜토리얼 없이 영역에 들어가 진행할 수 있는가, 반드시 거쳐야 하는가?
- 이미 학년을 아는 플레이어가 **직접 선택**으로 건너뛸 수 있는가?
