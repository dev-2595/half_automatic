# 지식 (Knowledge) — 기획 03: 튜토리얼과 레벨

> 상태: 초안 (v0.2) · 출처: 기획자 설정
> §1은 확정, §2는 확정 내용에서 도출한 규칙(제안), §3은 결정이 필요한 사항이다.
> 용어: **영역** = 과목 하나의 세계(기획자가 "지역·구역"이라 부르는 것). **구획** = 영역 안의 갈래 × 학교급 단위 (기획 01 §1.1).
> **학교급** = 초등 / 중등 / 고등. (기획자가 "학년"이라 부르기도 한다.)

## 1. 확정 사항

### 1.1 레벨

| # | 내용 |
|---|---|
| L1 | 레벨은 **1부터 100까지**다. |
| L2 | 레벨은 **영역(과목)마다 따로** 관리한다. 한 과목의 레벨과 점수는 다른 과목에 영향을 주지 않는다. |
| L3 | **100레벨 = 그 영역의 모든 개념과 심화를 익힌 수준**이다. (예: 수학에서 고등학교 3학년 심화까지 마치면 100레벨) |
| L4 | 100레벨은 **과목마다 각각** 달성해야 한다. |
| L5 | **학교급마다 최대 레벨이 있다.** 초등 **40**, 중등 **70**, 고등 **100**. 학교급의 최대 레벨에 이르면 **다음 학교급으로 넘어간다.** |
| L6 | 한 개념을 익히면 그 개념으로 **응용**을, 응용으로 **심화**를 한다. 각 단계에서 **경험치**를 얻는다. |

레벨 구간은 다음과 같다.

| 학교급 | 레벨 구간 | 레벨 수 |
|---|---|---|
| 초등 | 1 ~ 40 | 40 |
| 중등 | 41 ~ 70 | 30 |
| 고등 | 71 ~ 100 | 30 |

### 1.2 튜토리얼

| # | 내용 |
|---|---|
| T1 | 튜토리얼은 **영역마다 하나씩**, 총 **8개**다. |
| T2 | **가장 먼저 하는 튜토리얼(처음 들어간 과목)** 에서만 **조작법을 알려 준다.** 조작법 안내 후 테스트 문제를 내며 **보스가 소환**된다. |
| T3 | 그 뒤에 하는 **다른 영역의 튜토리얼은 조작법 없이 실력 테스트만** 한다. |
| T4 | **보스는 모든 튜토리얼에 나온다.** |
| T5 | 테스트 문제는 **과목마다 따로** 있다. |
| T6 | **튜토리얼은 실력 테스트이므로 건너뛸 수 없다.** |
| T7 | **조작법 안내는 건너뛸 수 있다.** |

### 1.3 실력 테스트 방식

1. 먼저 플레이어에게 묻는다: **"초등 / 중등 / 고등 중 어느 수준인가?"**
2. 플레이어가 고른 학교급의 문제를 낸다. (중등을 누르면 중등 문제, 고등이면 고등 문제, 초등이면 초등 문제)
3. 문제는 **여러 개념이 들어간 통합 문제**이며, **심화 · 응용 · 기초**로 이루어진다.
4. **학교급마다 9문제**다. (초등 9, 중등 9, 고등 9)
5. 문제 **9개 중 6개를 맞히면 그 학교급으로 배정**한다. **어떤 문제든** 상관없다.

## 2. 규칙으로 정리 (제안)

### 2.1 플레이어 진행 데이터

| 범위 | 항목 | 설명 |
|---|---|---|
| 전체 (1개) | `ControlsGuideResolved` | 조작법 안내를 **끝까지 봤거나 건너뛰었는가** (T7) |
| 영역별 (8개) | `TutorialDone` | 이 영역의 튜토리얼(실력 테스트)을 마쳤는가. **건너뛰기 상태는 없다** (T6) |
| 영역별 | `PlacementSchoolLevel` | 테스트로 배정된 학교급 (없음 / 초등 / 중등 / 고등) |
| 영역별 | `Level` | 1~100 |
| 영역별 | `Exp` | 현재 레벨의 누적 경험치 |

### 2.2 지켜야 할 불변 조건 (저장 데이터를 불러올 때 거부)

1. `Level`은 1 이상 100 이하이고 `Exp`는 0 이상이다.
2. `PlacementSchoolLevel`이 정해져 있으면 그 영역의 `TutorialDone`은 참이다. (`TutorialDone`이 거짓이면 학교급은 없음)
3. 어떤 영역이든 `TutorialDone`이 참이면 `ControlsGuideResolved`도 참이다. 조작법은 **처음 한 번만** 나온다.
4. 영역끼리 `Level`과 `Exp`를 **공유하지 않는다.** (L2)
5. `Level`은 배정된 학교급의 **시작 레벨(초등 1, 중등 41, 고등 71) 이상**이다. (Q2에서 "배정 시 시작 레벨"이 확정되면 적용)

### 2.3 튜토리얼 흐름

```
[처음 들어간 영역]  (조작법 안내: 건너뛰기 가능) → 수준 질문 → 테스트 문제 + 보스 → 6/9 이상이면 배정
[이후 다른 영역]    수준 질문 → 테스트 문제 + 보스 → 6/9 이상이면 배정
```

### 2.4 레벨과 경험치 데이터의 정합성

L3, L5 때문에 **한 학교급의 모든 스테이지 보상을 합친 경험치**가 **그 학교급 레벨 구간을 채우는 경험치**와 맞아야 한다.
(너무 적으면 다 마쳐도 최대 레벨에 못 가고, 너무 많으면 끝내기 전에 넘어가 버린다.)
데이터로 관리할 때 로드 시점에 검사한다. (제안)

1. 영역·학교급별 **스테이지 보상 총합 ≥ 그 구간(초등 1→40, 중등 41→70, 고등 71→100)을 채우는 경험치**
2. 그 학교급의 **마지막 스테이지를 빼면 총합 < 필요 경험치**
   → 학교급의 최대 레벨은 그 학교급을 모두 마쳐야만 도달한다. 고등에서는 L3(100레벨)이 된다.

## 3. 결정이 필요한 사항

### Q1. 테스트 결과와 시작 레벨
- 학교급에 배정되면 **그 학교급의 첫 레벨에서 시작**하는가? (초등 1, 중등 41, 고등 71) — 제안
  - 그렇다면 **고등을 골라 6개 맞히면 레벨 71에서 시작**하고, 초등·중등 내용은 건너뛴다. 의도한 것인가?
- 앞서 정한 **학년·레벨 직접 선택**([기획 01 D8](01_learning_structure.md))은 위 "수준 질문"과 **같은 것**으로 보면 되는가?

### Q2. 6개를 못 맞혔을 때
- 9개 중 **5개 이하**를 맞히면 어떻게 되는가? (예: 한 단계 낮은 학교급으로 배정 / 다시 선택해서 재응시 / 초등으로 배정)
- **초등을 골랐는데 6개를 못 맞히면?** (더 낮은 단계가 없다)
- 테스트를 **다시 볼 수 있는가?**

### Q3. 문제 구성
- "심화 · 응용 · 기초로 9개"는 **기초 3 + 응용 3 + 심화 3**인가? (그렇게 이해했다)
- 보스는 테스트 문제와 어떻게 연결되는가? (예: 문제를 맞히면 보스에게 피해, 틀리면 플레이어가 피해)
- 보스를 이기지 못해도 배정 결과는 **문제 정답 수만**으로 정하는가?

### Q4. 레벨과 갈래(기초·응용·심화) · 별의 관계
- 레벨 구간은 **학교급 기준**(초등 1~40 …)으로 정해졌다. 그 안에서 **기초 → 응용 → 심화**는 개념별 순서(L6)인가, 갈래 맵 단위인가?
- 별 3개가 무엇에 대응하는가 → [기획 01 §3 Q1](01_learning_structure.md)

### Q5. 조작법 안내
- 건너뛴 조작법을 **나중에 다시 볼 수 있는가?** (예: 설정 메뉴)
