# 지식 (Knowledge) — 기획 02: 스킬과 별 시스템

> 상태: 초안 (v0.1) · 출처: 기획자 설정
> §1은 확정, §2는 확정 내용에서 도출한 규칙(제안), §3은 결정이 필요한 사항이다.

## 1. 확정 사항

| # | 내용 |
|---|---|
| S1 | 모든 학습은 **가장 쉬운 것부터** 시작한다. (모든 영역이 1단계에서 시작) |
| S2 | 학습을 마치면 **스킬을 쓸 수 있게 된다.** 개념까지 모두 익혀야 한다. |
| S3 | **심화까지 모두 마치면** 그 스킬의 **별을 올릴 수 있다.** |
| S4 | 별은 스킬마다 **최대 3개**다. 각각 **초급 · 중급 · 상급**에 대응한다. |
| S5 | 별 3개를 모으면 그 스킬의 **정점**을 쓸 수 있다. 정점은 **매우 강력하고 이펙트가 매우 화려하다.** |
| S6 | 플레이어는 초반에 **점점 빠르게 성장**하는 경험을 한다. |

## 2. 규칙으로 정리 (제안)

### 2.1 스킬 하나의 상태

```
잠김 ─(개념·문제 학습 완료)→ 습득 ─(초급 심화)→ ★ ─(중급 심화)→ ★★ ─(상급 심화)→ ★★★ ⇒ 정점 해금
```

| 별 | 올리는 조건 (S3, S4에서 도출) |
|---|---|
| ★ 1개 | 초급 심화 완료 |
| ★★ 2개 | 중급 심화 완료 |
| ★★★ 3개 | 상급 심화 완료 → **정점 해금** |

### 2.2 지켜야 할 불변 조건 (데이터 무결성)

저장된 진행 데이터가 아래를 어기면 **로드 시점에 거부**한다. (신 데이터를 `FDeityTableValidator`가 검사하는 방식과 같다.)

1. 별 개수는 0 이상 3 이하다.
2. 습득하지 않은 스킬은 별이 0개다.
3. 별은 **한 번에 하나씩, 순서대로** 올라간다. (n번째 별은 n-1번째 별이 있어야 한다)
4. 별을 올리려면 해당 단계의 심화를 완료해야 한다.
5. 정점은 별이 정확히 3개일 때만 쓸 수 있다.
6. 별은 줄어들지 않는다. (줄이는 규칙이 별도로 정해지기 전까지)

### 2.3 별 외형 (확정: 모양과 색)

- **황금색 8각별.** 스킬 슬롯 옆에 최대 3개를 나란히 표시한다.
- 모양 참고: 기획자가 제시한 3D 8각별 이미지 (뾰족한 8개의 꼭짓점이 중심에서 퍼지고, 각 꼭짓점이 면으로 나뉘어 명암이 생기는 입체 별).
  원본은 은회색이며, 게임에서는 **금색**으로 만든다.
- 별이 아직 없는 칸은 **빈 윤곽 또는 어두운 별**로 보여 준다 (제안).
- ⚠ 참고 이미지는 출처·라이선스를 알 수 없어 저장소에 넣지 않았다. 게임 안의 별은 **직접 제작한 에셋**을 쓴다.

## 3. 결정이 필요한 사항

### Q1. "스킬을 쓸 수 있게 되는 조건"이 정확히 무엇인가?
말씀하신 "문제를 배우거나, 아니면 개념까지 모두 익히면"을 아래 중 무엇으로 이해해야 하는지 확인이 필요하다.

| 안 | 습득 조건 |
|---|---|
| A (권장) | **개념 학습 + 문제 풀이를 모두** 마쳐야 습득 |
| B | 둘 중 **하나만** 마쳐도 습득 (개념만 알아도, 문제만 풀어도 됨) |

### Q2. "스킬 하나"는 학습의 어떤 단위인가?
- 예) 구구단 2단 → 스킬 1개 / 한 단원 → 스킬 1개 / 한 교과 영역 전체 → 스킬 1개
- 한 영역(교과)에 스킬이 몇 개 있고, 영역마다 스킬 종류는 어떻게 다른가
- 스킬은 전투 기술인가, 탐험·퍼즐 같은 필드 능력도 포함하는가

### Q3. 초급·중급·상급의 의미
- 별 3개가 **같은 스킬의 난이도 3단계**인가?
  (예: 스킬 하나를 초급 문제 → 중급 문제 → 상급 문제로 심화)
- 아니면 초급·중급·상급이 **학년 구간**(초등·중등·고등)과 연결되는가?

### Q4. "점점 빠르게 성장" (S6)
- 초반에 레벨업·별 획득이 쉽고 후반으로 갈수록 느려지는 **성장 곡선**을 뜻하는가?
- 아니면 학습할수록 학습 속도 자체가 빨라지는 **보너스**를 뜻하는가?
