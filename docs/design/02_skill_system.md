# 지식 (Knowledge) — 기획 02: 스테이지, 스킬, 별 시스템

> 상태: 초안 (v0.2) · 출처: 기획자 설정
> §1은 확정, §2는 확정 내용을 맞춰 본 **제안(확인 필요)**, §3은 결정이 필요한 사항이다.

## 1. 확정 사항

| # | 내용 |
|---|---|
| S1 | 모든 학습은 **가장 쉬운 것부터** 시작한다. (모든 영역이 1단계에서 시작) |
| S2 | **스킬은 스테이지 하나를 클리어하면 얻는다.** |
| S3 | **스테이지는 한 개념**(예: 곱셈)을 **난이도 단계별로 나눈 학습 단위**다. |
| S4 | 스테이지를 클리어하면 그 단계에 맞는 스킬이 주어진다. (예: 구구단을 클리어하면 **기본 스킬**) |
| S5 | 스킬의 별은 **최대 3개**이며, **황금색 8각별**이다. |
| S6 | 별 3개를 모으면 그 스킬의 **정점**을 쓸 수 있다. 정점은 **매우 강력하고 이펙트가 매우 화려하다.** |
| S7 | 플레이어는 초반에 **점점 빠르게 성장**하는 경험을 한다. |

### 개념 하나의 난이도 단계 (예: 곱셈, 확정)

| 단계 | 곱셈의 예 |
|---|---|
| 기본 | 구구단 |
| 보통 | 십의 단위 곱셈 |
| 약간 심화 | 응용 |
| 심화 | 어려운 말, 다른 개념과의 조합 |

## 2. 제안: 별과 스테이지의 연결 (확인 필요)

단계가 **4개**(기본·보통·약간 심화·심화)이고 스킬 형태가 **기본 스킬 + 별 3개**이므로, 개수가 딱 맞는다.

```
개념(예: 곱셈) = 스킬 하나
 ├─ 기본 스테이지 클리어      → 스킬 습득 (기본 스킬)
 ├─ 보통 스테이지 클리어      → ★
 ├─ 약간 심화 스테이지 클리어 → ★★
 └─ 심화 스테이지 클리어      → ★★★ ⇒ 정점 해금
```

> ⚠ 이전 설정(별은 "초급·중급·상급" 각각의 심화를 마치면 오른다)과 표현이 다르다.
> 위 제안은 새로 주신 4단계 예시를 기준으로 맞춘 것이므로, 맞는지 확인이 필요하다.

### 2.1 지켜야 할 불변 조건 (데이터 무결성)

저장된 진행 데이터가 아래를 어기면 **로드 시점에 거부**한다. (신 데이터를 `FDeityTableValidator`가 검사하는 방식과 같다.)

1. 별 개수는 0 이상 3 이하다.
2. 습득하지 않은 스킬은 별이 0개다.
3. 별은 **순서대로** 올라간다. (n번째 별은 n-1번째 별이 있어야 한다)
4. 별은 해당 단계의 **스테이지를 클리어했을 때만** 오른다.
5. 정점은 별이 정확히 3개일 때만 쓸 수 있다.
6. 클리어한 스테이지 기록은 지워지지 않는다. (별 감소 규칙이 별도로 정해지기 전까지)

### 2.2 별 외형 (확정: 모양과 색)

- **황금색 8각별.** 스킬 슬롯 옆에 최대 3개를 나란히 표시한다.
- 모양 참고: 기획자가 제시한 3D 8각별 이미지 (뾰족한 8개의 꼭짓점이 중심에서 퍼지고, 각 꼭짓점이 면으로 나뉘어 명암이 생기는 입체 별). 원본은 은회색이며 게임에서는 **금색**으로 만든다.
- 별이 아직 없는 칸은 **빈 윤곽 또는 어두운 별**로 보여 준다 (제안).
- ⚠ 참고 이미지는 출처·라이선스를 알 수 없어 저장소에 넣지 않았다. 게임 안의 별은 **직접 제작한 에셋**을 쓴다.

## 3. 결정이 필요한 사항

### Q1. §2의 연결이 맞는가? (가장 중요)
- 맞다면: 개념 하나 = 스킬 하나, 4개 스테이지가 스킬 습득 + 별 3개에 대응.
- 다르다면: 별과 스테이지가 어떻게 연결되는지 알려 주세요.

### Q2. 스킬은 어떤 능력인가?
- 곱셈 스킬은 구체적으로 무엇을 하는가? (전투 공격, 방어, 필드 능력 등)
- 스킬 이름과 효과는 **개념의 성격**을 따르는가? (예: 곱셈 → 수치를 곱해서 키우는 효과)

### Q3. 개념과 영역의 관계
- 영역(예: 공간의 신 = 수학) 안에 개념이 여러 개 있고, 개념마다 스킬이 하나씩인가?
- 개념별 스테이지 목록과 진행 순서는 정해져 있는가? (예: 곱셈은 구구단 → 십의 단위 순서로만 열림)

### Q4. "점점 빠르게 성장" (S7)
- 초반에 별 획득이 쉽고 후반으로 갈수록 느려지는 **성장 곡선**인가?
- 아니면 학습할수록 학습 속도가 빨라지는 **보너스**인가?
