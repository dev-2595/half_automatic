## 4. 창세 연대기

순서가 확정된 사건만 기록한다.

1. **혼란의 진압** — 지식의 신이 잘못된 자, '혼란'을 잠재운다.
2. **세계 창조** — 얼마 남지 않은 힘을 쥐어짜 세상을 만든다.
3. **권속의 탄생** — 8신을 자신의 권속으로 삼는다.
4. **깊은 잠** — 모든 힘을 소진한 지식의 신이 깊은 잠에 빠진다.
