### 2.2 8 권속신

게임 안에서 신은 **개념의 이름**으로만 불린다. 교과는 내부 데이터일 뿐 플레이어에게 드러내지 않는다.
ID는 Unreal DataTable의 Row Name으로 그대로 사용하므로 고정한다.

| ID | 게임 속 이름 | 내부 담당 교과 (비공개) |
|---|---|---|
| `GOD_TIME` | 시간의 신 | 역사 |
| `GOD_JUSTICE` | 정의의 신 | 사회 |
| `GOD_LIFE` | 생명의 신 | 국어 |
| `GOD_REASON` | 이성의 신 | 과학 |
| `GOD_HARMONY` | 화합의 신 | 영어 |
| `GOD_DREAM` | 꿈의 신 | 정보 |
| `GOD_SPACE` | 공간의 신 | 수학 |
| `GOD_EMOTION` | 감정의 신 | 음악 |

> 변경 이력: 도덕 교과를 제외하고 사회를 정의의 신이 맡도록 바꾸었다. 이에 따라 질서의 신은 폐지했고, 빈 자리에 음악(감정의 신)을 넣었다.

### 2.3 연출 규칙 (확정)

- 지식의 신과 8 권속신은 **실루엣만** 보여준다. 얼굴·의상 같은 세부는 드러내지 않는다.
- 몰입감을 위해 게임 안 표기에 **교과 이름(국어·수학 등)을 쓰지 않는다.**
  교과와의 연결은 플레이하며 알아가는 요소로 남긴다.

## 4. 창세 연대기

순서가 확정된 사건만 기록한다.

1. **혼란의 진압** — 지식의 신이 잘못된 자, '혼란'을 잠재운다.
2. **세계 창조** — 얼마 남지 않은 힘을 쥐어짜 세상을 만든다.
3. **권속의 탄생** — 8신을 자신의 권속으로 삼는다.
4. **깊은 잠** — 모든 힘을 소진한 지식의 신이 깊은 잠에 빠진다.
5. **영역의 창조** — 깊은 잠에 든 지식의 신을 대신해, 8 권속신이 이 세상에 각자의 **영역**을 만든다.

## 5. 영역 (확정)

- 8 권속신은 각자 자신의 **영역**을 만든다. 영역은 총 8개다.
- 플레이어는 **어느 영역으로 갈지 직접 선택**한다.
- 플레이어는 **여러 영역을 오갈 수 있다.** 따라서 여러 교과를 동시에 병행해서 학습할 수 있다.
- 영역 이름은 게임 안에서 개념으로 표현한다 (신과 동일하게 교과명을 드러내지 않는다).
