# 지식 (Knowledge) — 아트 01: 캐릭터 그림체

> 상태: 초안 (v0.1) · 출처: 기획자 스케치 (`reference/character_style_v1.png`)
> **원본 스케치에서 직접 확인되는 사항**과 **해석이 들어간 사항**을 구분해 기록한다.

![캐릭터 그림체 원본 스케치](reference/character_style_v1.png)

## 1. 기본 방향

- 단순한 그림체 (기획자 지정)
- 3면도 제공: **앞 / 옆 / 뒤**

## 2. 스케치에서 확인되는 형태

원본 앞모습 기준 픽셀 측정값(대략)이며, 손그림이므로 ±10% 오차를 전제로 한다.

| 부위 | 형태 | 비율 근거 |
|---|---|---|
| 머리 | 거의 완전한 원. 목 없이 몸통에 바로 붙음 | 머리 높이 ≈ 205px |
| 몸통 | 아래로 약간 넓어지는 둥근 덩어리 | 몸통+다리 높이 ≈ 200px |
| 다리 | 몸통 하단 가운데의 홈으로만 두 다리를 구분. 짧고 뭉툭함 | 다리 ≈ 몸통 높이의 40% |
| 팔 | 어깨에서 몸통 옆을 따라 늘어지는 가는 팔. 손가락 없이 끝이 안쪽으로 살짝 말림 | 손끝이 다리 시작 높이 근처 |
| 얼굴·머리카락 | 그려져 있지 않음 | — |

**종합 비율: 머리 : 몸 ≈ 1 : 1, 전체 약 2등신.**

### 시점별 특징
- **앞**: 좌우 대칭. 팔은 몸통 양옆에 붙어 늘어짐.
- **옆**: 몸통 폭이 좁아지고, 팔이 몸 앞쪽으로 비스듬히 내려옴.
- **뒤**: 앞모습과 같은 실루엣. 팔이 몸통 양옆으로 살짝 보임.

## 3. 해석이 들어간 사항 (확인 필요)

- [ ] **팔 보조선**: 앞모습 뒤의 반투명한 날개 모양 4개는 날개가 아니라,
      "팔이 이렇게 생겼다는 것을 보여주기 위해 4개 더 그림"이라는 메모에 따라
      **팔의 형태·움직임을 보여주는 참고 스케치**로 해석했다.
- [ ] **머리 위 짧은 선**: 앞모습 머리 위의 짧은 가로선이 머리카락(삐친 머리)인지, 단순한 선 겹침인지 불명.
- [ ] **크기 차이**: 옆·뒤 모습이 앞모습보다 작게 그려진 것은 같은 캐릭터의 작화 편차로 간주했다.
- [ ] **얼굴**: 표정·눈·입을 넣을지, 얼굴 없는 디자인을 유지할지.

## 4. 미정 사항

- [ ] 색감(채색 방식, 외곽선 유무)
- [ ] 3D 모델로 구현할지, 2D 스프라이트로 구현할지
- [ ] 신(지식의 신, 8 권속신)과 플레이어·NPC를 구분하는 방식 (크기, 장신구, 색 등)
