# 지식 (Knowledge) — 아트 03: 캐릭터 커스터마이징 요구사항

> 상태: 초안 (v0.2) · 출처: 기획자 요구 ("뼈대 위에 체격 조정, 복잡한 얼굴, 화려한 의상이 가능해야 함")
> 이 문서의 **요구사항(§1)** 은 확정, **구현 방향(§2~3)** 은 제안이며 기획자 확인이 필요하다.

## 1. 요구사항 (확정)

아트 01의 마네킹은 **모든 캐릭터의 출발점(기본 상태)** 이지, 최종 모습이 아니다.
그 위에서 아래 세 가지가 가능해야 한다.

| # | 요구 | 예시 |
|---|---|---|
| R1 | **체격 조정** | 키, 머리 크기, 몸통 폭, 팔다리 길이·굵기 |
| R2 | **복잡한 얼굴** | 단순한 점 눈이 아니라 눈·눈썹·입·장식 등 세부 표현 |
| R3 | **화려한 의상** | 복잡한 형태의 옷, 망토, 장신구, 무기 |

## 2. 구현 방향 (제안)

이 요구는 "완성된 캐릭터 모델을 가져다 쓰는 방식"으로는 충족하기 어렵다.
**하나의 공용 뼈대 위에 교체·조절 가능한 부품을 얹는 구조**가 필요하다.

| 요구 | 방법 | Unreal 기능 |
|---|---|---|
| 공용 뼈대 | 모든 캐릭터가 같은 Skeleton을 쓴다. 애니메이션을 한 번만 만들어 전원이 공유 | Skeleton / Animation Retarget |
| R1 체격 | 기본 몸 메시에 **모프 타깃**(형태 변형 슬라이더)을 만들어 값으로 조절 | Skeletal Mesh Morph Target |
| R2 얼굴 | 얼굴을 몸과 **분리된 부품**으로 두고, 눈·입·장식을 교체하거나 텍스처·머티리얼 값으로 표현 | 별도 Skeletal Mesh + Material Parameter |
| R3 의상 | 의상을 **슬롯별 부품**(상의, 하의, 신발, 망토, 머리 장식…)으로 만들어 몸에 얹는다 | Leader Pose Component, Socket |
| 몸 뚫림 방지 | 의상이 덮는 몸 부분을 숨기거나, 체격 변화에 맞춰 의상도 같은 모프를 적용 | Mesh 마스킹, 동일 Morph 적용 |
| 망토·치마 | 흔들리는 천은 물리 시뮬레이션 | Chaos Cloth |

> 후보 도구: Unreal의 **Mutable(Customizable Objects)** 플러그인은 부품 조합·모프를 한꺼번에 다루지만,
> 5.x에서 실험적 기능일 수 있다. 채택 전에 사용 중인 엔진 버전에서 상태를 확인한다.

## 3. 설계 제약 (제안)

- **그림체 유지**: 무한정 바꾸면 "단순한 그림체" 정체성이 사라진다.
  체격 슬라이더에 **허용 범위(최소·최대)** 를 두고, 기본 비율(머리:몸 ≈ 1:1)에서 너무 멀어지지 않게 한다.
- **데이터 기반**: 외형은 코드가 아니라 데이터(체격 값 + 얼굴 부품 ID + 의상 슬롯별 ID)로 표현한다.
  신·NPC·플레이어가 모두 같은 구조를 쓰고, 이후 세이브·상점·도감과 연결하기 쉽다.
- **검증**: 범위를 벗어난 체격 값, 존재하지 않는 부품 ID, 같은 슬롯에 중복 장착은 로드 시점에 거부한다
  (신 데이터에서 `FDeityTableValidator`가 하는 것과 같은 방식).
- **책임 분리**: 외형 데이터 정의 / 외형 검증 / 외형을 메시에 적용하는 컴포넌트를 서로 다른 클래스로 둔다.

## 4. 에셋 조달에 미치는 영향

- 완성된 캐릭터 팩은 보통 메시가 하나로 고정되어 있어 R1~R3을 직접 충족하기 어려울 것으로 예상된다
  (실제 파일 구조는 내려받아 확인해야 한다).
- 따라서 외부 에셋은 **참고 자료, 임시 모델, 소품·의상 부품** 용도로 쓰고,
  **기본 몸(마네킹)은 모프 타깃을 포함해 직접 제작**하는 방향을 권장한다 (Blender 등).
  → [아트 02](02_asset_sourcing.md) 의 권장안을 이에 맞게 수정함.

## 5. 확정된 사항

- [x] **3D**로 제작한다 (기획자 확인). 따라서 §2의 공용 뼈대 + 모프 타깃 + 부품 조합 방식을 기본으로 한다.
- [x] 엔진은 **Unreal Engine** (기획자 확인).

## 6. 미정 사항

- [ ] 기본 몸을 직접 제작할 수 있는가, 외주·구매가 필요한가
- [ ] 체격 슬라이더 항목과 허용 범위
- [ ] 얼굴을 부품 교체식으로 할지, 텍스처 합성식으로 할지
- [ ] 플레이어가 외형을 직접 꾸미는 기능이 필요한가, 개발자가 NPC·신 외형만 만드는가
